02 — Philosophy

Economic Ways.

Il mio approccio allo sviluppo: soluzioni minime che funzionano, zero componenti inutili. Ogni dipendenza che non aggiungi è manutenzione che non paghi — e un tool che qualsiasi developer può toccare dopo la consegna.

  • HTML + Alpine.jsReattività senza runtime overheadReact / Next.js
  • Pico.cssStili semantici, zero class soupTailwind
  • DuckDB in-processSQL analitico, zero serverPostgres + ORM
  • SQLite on-deviceLocale, privato, veloceCloud sync
  • Static hostingZero ops, CDN istantaneoServerless infra
  • PolarsDataframe veloci, tipi nativipandas
# Economic Ways — applicato import duckdb import polars as pl def analizza_magazzino(path: str) -> pl.DataFrame: """Query diretta su CSV. Niente ORM. Niente boilerplate. Niente cloud.""" return duckdb.sql( f"SELECT articolo, SUM(qty)" f" FROM read_csv_auto('{path}')" f" GROUP BY 1 ORDER BY 2 DESC" ).pl() # Questo. Ship it.
